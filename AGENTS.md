# Работа с проектом

- Рабочая копия: корень этого репозитория, без вложенной копии проекта.
- Стек: Python 3.11+, Flask, SQLite, SQLAlchemy, Flask-Login, Flask-WTF.
- Интерфейс и пользовательские сообщения — на русском языке.
- Не удалять `instance/olympiad.db`, `.env` и локальный секрет при разработке.
- Ответы задач остаются только в серверном коде начального наполнения и базе; сериализация задач — через `Task.public_dict()`.
- Баллы вычисляются по `solved_tasks`. Сохранять уникальность `(user_id, task_id)` и атомарность попытки с решением.
- Все изменяющие запросы должны проверять CSRF. Личность берётся только из Flask-Login.
- Перед сдачей изменений выполнить `.\.venv\Scripts\python.exe -m pytest` и проверить затронутые страницы.
- Тесты используют только базы внутри `.pytest_tmp/`; HTTP-проверка — `.local/http-check/`. Не использовать рабочую базу для автотестов.
- Не коммитить окружение, базы, секреты, `.idea/`, `.local/` и кэш.
